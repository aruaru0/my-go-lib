# LevenshteinDistance — 編集距離

2つの文字列がどの程度異なっているかを示す指標で、1文字の「挿入」「削除」「置換」によって一方の文字列を他方に変形するために必要な最小の手順数を求めるアルゴリズムです（編集距離）。

## 主なユースケース（どういう時に使うか）

- スペルチェッカーや、入力ミスの自動補正提案
- 自然言語処理における文章の類似度判定や類似検索
- **遺伝子配列（DNAなど）の類似性の比較**

## なぜ使うのか（メリット）

- 動的計画法（DP）を用いて、2つの文字列長を $N, M$ としたとき $O(N \times M)$ の時間および空間計算量で厳密な最小編集回数を求められます。

---

## 関数

- `LevenshteinDistance(s, t string) int` — 2 つの文字列間の Levenshtein 距離 (1 文字編集の最小回数) を返します

## 使用例

```go
d := mylib.LevenshteinDistance("kitten", "sitting")
// d = 3
```
