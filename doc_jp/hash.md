# Hash — シンプルな整数ハッシュ関数

文字列やデータに対するハッシュ値を計算する、あるいはハッシュ衝突の低減をサポートするための基本的なハッシュユーティリティです。

## 主なユースケース（どういう時に使うか）

- 文字列やオブジェクトの比較を高速化するための識別子生成
- ハッシュテーブルやカスタム連想配列のキー値の分散

## なぜ使うのか（メリット）

- シンプルかつ高速に動作するハッシュ関数を提供し、データの一致判定などを定数時間で可能にします。

---

## 関数

- `HashInts[T Integer](x []T) int` — `ret = ret*37 + e` を法 `1e9+7` で適用して整数スライスのハッシュを計算します。
