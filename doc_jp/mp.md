# MP — 文字列パターンマッチング (Morris-Pratt アルゴリズム)

テキストからパターンを検索する文字列探索アルゴリズムで、KMPアルゴリズムの基本形となるものです。

## 主なユースケース（どういう時に使うか）

- 単一の固定キーワードに対する文字列探索
- **文字列の自己周期（繰り返しパターン）の検出**

## なぜ使うのか（メリット）

- テーブル構築がKMPよりもシンプルで実装しやすく、テキスト長 $N$ に対する線形時間 $O(N + M)$ での安全な探索を提供します。

---

## 型

- `MP` — パターンマッチャー構造体

## 関数

- `NewMP(pattern string) *MP` — 新しいパターンマッチャーを作成します
- `(*MP).FindAll(text string) []int` — テキスト内のパターンのすべての開始位置を返します

## 使用例

```go
mp := mylib.NewMP("abc")
pos := mp.FindAll("abcabcabc")
// pos = [0, 3, 6]
```
