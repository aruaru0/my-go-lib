# divsubstr

数字のみからなる文字列 $s$ の連続する部分文字列が表す数値のうち、指定された整数 $p$ で割り切れるものの個数をカウントするアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- 大量桁の数表示文字列における、特定の素数の倍数となるパターンの計数
- 文字列検索や暗号解読における、特定の算術的条件を満たすブロックの抽出

## なぜ使うのか（メリット）

- 単純に部分文字列を全走査すると $O(N^2)$ かかる計算を、累積和と剰余のハッシュマップを用いることで $O(N)$ または素数 $2, 5$ の特質を利用して線形時間で超高速に処理できます。

---

## 関数

```go
func CountDivisibleSubstrings(s string, p int) int
```

## CountDivisibleSubstrings

`s` の部分文字列のうち、`p` で割り切れるものの個数をカウントします。右から左への mod 累積と、マップを使用した剰余の追跡を行います。`p = 2` または `p = 5` の場合は、特別に最適化された経路を使用します。
