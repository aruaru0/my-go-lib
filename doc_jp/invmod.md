# invmod

ある整数 $a$ に対して、ある法 $m$ において $a \times x \equiv 1 \pmod m$ を満たす逆元 $x$ を計算する関数です。

## 主なユースケース（どういう時に使うか）

- **剰余演算（Mod）を含む数式において、割り算（$\div a$）を掛け算（$\times a^{-1}$）に変換する処理**
- 組み合わせ数 $nCr \pmod p$ を高速に求めるための階乗の逆元の算出

## なぜ使うのか（メリット）

- 拡張ユークリッドの互除法を用いることで、 $a$ と $m$ が互いに素であれば $O(\log m)$ の時間で確実に逆元を求められます。

---

## 関数

```go
func InvModTable(n, m int) []int
```

長さ `n` の配列を返します。`ret[i] = i^{-1} mod m` (ただし `1 <= i < n`) です。漸化式 `inv[i] = m - m/i * inv[m%i] % m` を使用します。

## 使用例

```go
inv := mylib.InvModTable(10, 13)
// inv[1..9] は 13 を法とするモジュラ逆数
```
