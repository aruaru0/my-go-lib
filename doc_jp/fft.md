# fft

離散フーリエ変換（DFT）とその逆変換を高速に行うことで、信号処理や多項式の乗算（畳み込み）を劇的に高速化するアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- 音声や画像の周波数解析・フィルタリング処理
- **巨大な多項式の乗算や超多桁の掛け算（畳み込みによる実装）**

## なぜ使うのか（メリット）

- 定義通りに計算すると $O(N^2)$ かかる離散フーリエ変換を、分割統治法を用いて $O(N \log N)$ で処理し、大規模データに対しても実用的な処理速度を提供します。

---

## 関数

```go
func FFT(x []complex128, n int) []complex128
func IFFT(x []complex128, n int) []complex128
```

`FFT` は離散フーリエ変換を計算し、`1/n` で正規化します。`IFFT` は逆変換を計算します。

## 使用例

```go
n := 8
x := make([]complex128, n)
for i := 0; i < n; i++ {
    x[i] = complex(float64(i+1), 0)
}
f := mylib.FFT(x, n)
inv := mylib.IFFT(f, n)
// inv ≈ x (浮動小数点誤差の範囲内)
```
