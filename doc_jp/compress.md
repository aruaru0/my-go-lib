# compress

大小関係を維持したまま、非常に大きな値の範囲を持つ配列の要素を、 $0$ から始まる連続した整数（インデックス）に変換する処理です（座標圧縮）。

## 主なユースケース（どういう時に使うか）

- 座標の範囲が $10^9$ など非常に広大だが、出現する点の個数 $N$ が $10^5$ 程度と少ない状況で、配列やセグメント木、BITなどのインデックスとして利用できるようにしたい場合
- 平面上の区間や矩形のクエリをグリッド上で効率的に処理したい場合

## なぜ使うのか（メリット）

- データの相対的な大小関係や順序を崩さずに、メモリや空間計算量を $O(値の範囲)$ から $O(N)$ に大幅に削減し、各種データ構造に適用可能にします。

---

## 関数

```go
func Compress[T Ordered](s []T) []int
```

## Compress

`s` の各要素に対応する順位 (0 から始まる) を整数スライスとして返します。順位はソートされた一意な値に基づきます。`Ordered` 制約を満たす任意の型 (int 系、float 系、string) をサポートします。
