# Dinic

ネットワーク（有向グラフ）において、始点（ソース）から終点（シンク）へ流すことができる最大流量を求めるアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- 水道網、道路網、情報通信ネットワークにおける最大輸送量の算出
- **二部マッチング問題（仕事と人員の最適な割り当てなど）の解決**
- **プロジェクトのタスク依存関係を考慮した最大利益の選定（燃やす埋める問題）**

## なぜ使うのか（メリット）

- 辺の容量が整数である場合、残余グラフ上の最短路階層グラフを繰り返し構築することで、多くの実用的なグラフにおいて $O(V^2 E)$ という優れた時間計算量で最大流を計算できます（二部マッチングでは $O(E \sqrt{V})$）。

---

## コンストラクタ

```go
func NewDinic(N int) *Dinic
```

`N` 個の頂点 (0..N-1) を持つ新しいフローネットワークを作成します。

## メソッド

```go
func (d *Dinic) AddEdge(from, to, cap int)
```
容量 `cap` の有向辺を追加します。

```go
func (d *Dinic) MaxFlow(s, t int) int
```
`s` から `t` への最大流を計算します。

## 使用例

```go
d := NewDinic(4)
d.AddEdge(0, 1, 10)
d.AddEdge(0, 2, 5)
d.AddEdge(1, 2, 15)
d.AddEdge(1, 3, 10)
d.AddEdge(2, 3, 10)
flow := d.MaxFlow(0, 3)
fmt.Println(flow) // 15
```

## 計算量

O(V²·E) 時間、O(V + E) 空間です。
