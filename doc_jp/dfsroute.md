# DFSRoute

深さ優先探索（DFS）を用いてグラフ上の始点から終点までの経路を探索し、その通過する頂点リストを復元するアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- 迷路やグリッドマップでの、スタートからゴールまでの到達可能ルートの1つの検出
- グラフの連結性確認と同時に、具体的な移動パスの提示

## なぜ使うのか（メリット）

- 再帰呼び出しやスタックを用いたシンプルな実装で、 $O(V + E)$ の時間計算量で到達経路を1つ発見し、直ちにその詳細経路を復元できます。

---

## 型

```go
type Node struct {
    To []int
}
```

## 関数

```go
func DFSRoute(nodes []Node, from, to int) []int
```

`from` から `to` への経路を頂点インデックスのスライスとして返します。経路が存在しない場合は `nil` を返します。グラフはサイクルを含んではいけません。

## 使用例

```go
nodes := []Node{
    {To: []int{1, 2}},
    {To: []int{0, 3}},
    {To: []int{0, 3}},
    {To: []int{1, 2}},
}
route := DFSRoute(nodes, 0, 3)
fmt.Println(route) // [0 1 3] または [0 2 3]
```

## 計算量

O(V + E) 時間、O(V) 空間です。
