# matrixpow

正方行列 $A$ に対し、その $N$ 乗である $A^N$ を計算するアルゴリズムです（繰り返し二乗法）。

## 主なユースケース（どういう時に使うか）

- **線形漸化式（フィボナッチ数列など）の第 $N$ 項の高速計算（行列累乗による高速化）**
- マルコフ連鎖や状態遷移モデルにおいて、 $N$ ステップ後の遷移確率分布の算出

## なぜ使うのか（メリット）

- 繰り返し二乗法により行列の乗算回数を $O(\log N)$ に短縮し、 $N = 10^{18}$ などの天文学的なステップ数でも一瞬で計算できます。

---

## 関数

```go
func PowMatrix[T Integer](A [][]T, p int, mod T) [][]T
```

## 使用例

```go
A := [][]int{{1, 1}, {1, 0}}
P := mylib.PowMatrix(A, 10, 1000000007)
// P = [[89, 55], [55, 34]]  (フィボナッチ数)
```
