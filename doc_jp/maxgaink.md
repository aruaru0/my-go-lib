# maxgaink

`MaxGain` アルゴリズムの拡張版で、初期位置を任意の頂点 $i$ に指定して、最大 $K$ 回の遷移による累積スコアの最大値を計算します。

## 主なユースケース（どういう時に使うか）

- 異なる複数の開始地点からゲームを開始したとき、それぞれの地点から得られる最大得点を見積もる場合

## なぜ使うのか（メリット）

- 任意の開始点 $i$ から始まる経路について、ループ部分とプレフィックス部分を切り分けて分析するため、 $O(\text{閉路の長さ})$ という高速な時間計算量で処理できます。

---

## 関数

```go
func MaxGainK(i, N, K int, p, c []int) int
```

## MaxGainK

位置 `i` から開始し、`p` (1-indexed の次の位置) で定義される辺に沿って最大 K 回移動できます。各ノード `v` を訪れると `c[v]` の利得が得られます。到達可能な最大総利得を返します。関数グラフ内のサイクルを検出し、それを利用して計算を高速化します。
