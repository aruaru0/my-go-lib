# BaseConv — 負の基数への変換

整数を負の数を含む任意の整数を底（基数）とする表現に変換します（例: -2進数）。

## 主なユースケース（どういう時に使うか）

- 負の基数における数値表現のシミュレーション
- 特殊な進数表現を用いる数論の問題やアルゴリズムコンテストの問題解決

## なぜ使うのか（メリット）

- 通常の正の基数変換と同様の剰余と除算のループにより、負の基数であっても符号付き桁を使わずに一意の表現（各桁が $0 \le d < |n|$）を $O(\log_{|n|} x)$ で効率的に求められます。

---

## 関数

- `ToBaseN[T Integer](x T, n T) []T` — 整数 x を基数 n に変換します。負の基数 (-2, -3 など) もサポートします。リトルエンディアン順 (最下位桁が先) で桁を返します。
