# AhoCorasick — 複数パターン文字列マッチング

Aho-Corasick（エイホ-コーラシック）アルゴリズムは、**1つのテキストから複数のパターン（キーワード）を同時に、かつ高速に検索する**ための文字列探索アルゴリズムです。

## 主なユースケース（どういう時に使うか）

- **不適切ワード（NGワード）やスパムのフィルタリング**
  - チャット、掲示板、SNSなどで、数千〜数万個の禁止ワードリストに含まれる単語が投稿テキストに含まれているかを一括で判定・検出する。
- **ログ解析や侵入検知システム（IDS）**
  - 大量のサーバーログやネットワークパケットから、既知の攻撃パターン（シグネチャ）をリアルタイムでスキャンする。
- **ドキュメントの自動タグ付け・キーワード抽出**
  - ブログ記事やニュース文書から、あらかじめ用意した辞書（人名、地名、専門用語など）に合致する単語をすべて抽出する。
- **バイオインフォマティクス（遺伝子情報解析）**
  - 長大なDNA配列データの中から、複数の特定の塩基配列（遺伝子パターン）を高速に探索する。

## なぜ使うのか（メリット）

単純に「すべてのパターンについて1つずつ検索（`strings.Contains` など）」を行うと、パターン数 $K$ とテキスト長 $N$ に対して $O(K \times N)$ に近い時間がかかってしまいます。
Aho-Corasick を使うことで、パターンがどれだけ多くても**テキストを1回走査するだけ**（計算量 $O(N + マッチ数)$）で、すべての登録パターンを漏れなく高速に検出できます。

---

## 型

- `AhoCorasick` — Aho-Corasick オートマトン
- `AhoMatch` — 位置におけるマッチしたパターンを表します

## 関数

- `NewAhoCorasick() *AhoCorasick` — 新しいオートマトンを作成します
- `(*AhoCorasick).Add(pattern string) int` — パターンを追加し、その ID を返します
- `(*AhoCorasick).Build()` — 失敗リンクを構築します (すべてのパターンを追加した後に呼び出します)
- `(*AhoCorasick).Search(text string) []AhoMatch` — すべてのマッチ (位置, ID) を返します
- `(*AhoCorasick).MatchCount(text string) int` — マッチの総数を返します
- `(*AhoCorasick).GetMask(v int) int` — 状態 `v` のパターンマッチマスクを返します

## 使用例

```go
ac := mylib.NewAhoCorasick()
ac.Add("he")
ac.Add("she")
ac.Add("hers")
ac.Build()
matches := ac.Search("ushers")
// matches: 位置 1 (she), 位置 2 (he), 位置 2 (hers)
```
