# MaxGain — K 回の移動における最大利得

遷移先が1つに決まる機能グラフにおいて、頂点0から出発して最大 $K$ 回遷移したときに得られる累積スコアの最大値を求めるアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- ループ構造を持つゲームや得点シミュレーションで、移動限界 $K$ の中で最大の得点を得る戦略の検証

## なぜ使うのか（メリット）

- 閉路（ループ）に到達した際、そのループの1周あたりのスコアが正か負かを判別し、ループ可能な回数を用いて $O(\text{閉路の長さ})$ の時間で、超巨大な $K$ に対する最大スコアを高速計算します。

---

## 関数

```go
func MaxGain(N, K int, p, c []int) int
```

MaxGain は、ノード 0 から開始して関数グラフに沿って 1 回から K 回移動することで得られる最大総利得を計算します。`p[i]` は 1-indexed の移動先、`c[i]` はノード i での利得です。

サイクルを検出し、最適な繰り返しを計算することで処理します。
