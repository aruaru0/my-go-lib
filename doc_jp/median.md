# median

数列に新しく要素を追加する操作と、その時点での中央値（Median）を取得する操作を同時にサポートするデータ構造です（通常、2つの優先度付きキューを使用）。

## 主なユースケース（どういう時に使うか）

- リアルタイムで観測値が追加されるストリーミングデータにおける、中央値の継続的な監視
- **スライディングウィンドウ内でのロバストな統計値（中央値）の算出**

## なぜ使うのか（メリット）

- 毎回ソートし直すと $O(N \log N)$ かかる処理を、要素追加を $O(\log N)$、中央値取得を $O(1)$ という極めて高いパフォーマンスで提供します。

## 型

```go
type Median struct { ... }
func NewMedian() *Median
func (m *Median) Add(x int)
func (m *Median) Remove(x int)
func (m *Median) Median() int
```

## Median

整数のマルチセットを管理し、中央値のクエリをサポートします。2 つのヒープ (下半分は最大ヒープ、上半分は最小ヒープ) で実装されています。要素数が偶数の場合は、中央の 2 つの値の平均の floor を返します。
