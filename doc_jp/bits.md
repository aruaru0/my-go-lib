# bits

整数の2進数表現におけるビット操作（2の冪乗への切り上げや最下位ビットの探索など）を高速に行うための便利関数群です。

## 主なユースケース（どういう時に使うか）

- **セグメント木などの二分木構造で、サイズを2の冪乗に揃えるためのサイズ決定（CeilPow2）**
- **ビット列の中で最初（最下位）に1が立っている位置を求める処理（Bsf）の高速化**

## なぜ使うのか（メリット）

- Goの標準ライブラリ（`math/bits`）や高速なビット演算を活用することで、ループ処理を行わずに $O(1)$ もしくは極めて少ないステップ数でビット情報を計算・操作できます。

---

## 関数

```go
func CeilPow2(n int) int
func Bsf(n uint) int
```

## CeilPow2

`2^x >= n` を満たす最小の `x` を返します。

## Bsf

前方ビットスキャンです。`n` の末尾のゼロビットの数を返します (`bits.TrailingZeros` を使用します)。
