# extgcd

2つの整数 $a, b$ に対し、最大公約数 $d = \gcd(a, b)$ を求めると同時に、一次不定方程式 $ax + by = d$ の整数解 $(x, y)$ を1つ求めるアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- **モジュラ逆数（ある数 $a$ に対する $\pmod m$ での逆元 $x$、すなわち $ax \equiv 1 \pmod m$）の計算**
- **中国剰余定理（CRT）による合同方程式の解決**

## なぜ使うのか（メリット）

- ユークリッドの互除法と同じ $O(\log(\min(a, b)))$ のステップ数で、追加コストをほとんどかけずに不定方程式 of 解を直接算出できます。

---

## 関数

```go
func ExtGcd[T Integer](a, b T) (T, T, T)
```

`(g, x, y)` を返します。ただし `a*x + b*y = g = gcd(a, b)` を満たします。

## 使用例

```go
g, x, y := mylib.ExtGcd(6, 15)
// g = 3, x = -2, y = 1
// 6*(-2) + 15*1 = 3 = gcd(6, 15)
```
