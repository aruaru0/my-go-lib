# ncrautogen

必要に応じてオンデマンドで二項係数 $nCr \pmod P$ の前処理テーブルを自動で拡張・生成し、必要十分な範囲の値を管理するライブラリです。

## 主なユースケース（どういう時に使うか）

- あらかじめ $N$ の最大値が固定できない、または動的に範囲を広げながら二項係数を使用したい計算処理

## なぜ使うのか（メリット）

- メモリ使用量を必要最小限に抑えつつ、上限が不明な $N$ に対しても要求に応じてテーブルを動的に再割り当て・拡張して $O(1)$ のクエリ性能を維持します。

---

## 型

```go
type NCRGenerator struct { ... }
```

## 関数

```go
func NewNCRGenerator(mod int) *NCRGenerator
```

## メソッド

```go
func (g *NCRGenerator) NCR(n, r int) int
```

`nCr` を `mod` で割った剰余を計算します。階乗テーブルは必要に応じて自動的に拡張されます。

## 使用例

```go
g := mylib.NewNCRGenerator(1000000007)
c := g.NCR(5, 2) // 10
c = g.NCR(10, 3) // 120
c = g.NCR(100, 50) // 自動的にテーブルが拡張されます
```
