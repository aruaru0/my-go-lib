# nary

指定された桁数の $N$ 進数のすべての組み合わせパターンを、ジェネレータ（チャンネル）を介して順次列挙するアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- **全てのパターンを総当たりで調べる全探索（ブルートフォース検索）**
- $N$ 種類の手を持つゲームにおける、指定手数までの全手順の生成

## なぜ使うのか（メリット）

- Goのチャンネル（`chan string`）を利用した非同期ジェネレータとして実装されているため、呼び出し側はメモリにすべてのパターンを溜め込むことなく、必要なときに順次データを受け取って省メモリで処理できます。

---

## 関数

```go
func NaryNumbers(N, digits int) <-chan string
```

## NaryNumbers

最大 `digits` 桁のすべての N 進数を文字列として生成し、チャネルを通じてストリーミングします。
