# BIT — Binary Indexed Tree (int 用 Fenwick 木)

配列の要素 of 更新と、任意の区間の和の計算を、それぞれ $O(\log N)$ の高速な計算量で行うことができるデータ構造です（Binary Indexed Tree）。

## 主なユースケース（どういう時に使うか）

- **配列の値が頻繁に更新される状況での、累積和（区間和）の高速クエリ**
- **転倒数（反転数、バブルソートの交換回数）の高速な計算**
- 動的なデータの順位付けやインデックス管理

## なぜ使うのか（メリット）

- セグメント木（Segment Tree）と比較して、実装が極めてシンプルでコード量が少なく、定数倍の処理速度も非常に高速です。
- メモリ使用量が元の配列と同等の $O(N)$ で済みます。

---

## 関数

- `NewBIT(n int) *BIT` — サイズ n の BIT を作成します (0-indexed の位置 0..n-1)
- `(*BIT).Add(k, v int)` — インデックス k の要素に v を加算します
- `(*BIT).Sum(k int) int` — [0, k] (両端を含む) の要素の和を返します。k < 0 の場合は 0、k >= n の場合は n-1 にクランプされます。
- `(*BIT).RangeSum(l, r int) int` — [l, r) の要素の和を返します (l を含み、r は含みません)。l >= r の場合は 0 を返します。
