# Sliding Window (スライド最小値・最大値)

配列上を一定 of 幅 $K$ の窓（ウィンドウ）を右へずらしていき、各位置でのウィンドウ内の最小値（または最大値）を効率的に求めるアルゴリズムです（スライド最小値）。

## 主なユースケース（どういう時に使うか）

- 音声や画像のフィルター処理における、近傍ピクセル内の最大・最小値の抽出
- 時系列データにおける一定期間内の最大・最小イベントの検知
- **動的計画法（DP）における遷移範囲制限の高速化**

## なぜ使うのか（メリット）

- 両端キュー（Deque）を用いて、以前に現れた不要な値を効率的に取り除くことで、各要素を最大でも2回（追加と削除）しか操作せず、全体の計算量を $O(N)$ の線形時間で処理できます。

---

## 使用例

```go
package main

import (
	"fmt"
	"github.com/aruaru0/my-go-lib"
)

func main() {
	a := []int{1, 3, -1, -3, 5, 3, 6, 7}
	fmt.Println(mylib.SlideMin(a, 3)) // [-1 -3 -3 -3 3 3]
	fmt.Println(mylib.SlideMax(a, 3)) // [3 3 5 5 6 7]
}
```

## 関数シグネチャ

```go
func SlideMin[T Ordered](a []T, k int) []T
func SlideMax[T Ordered](a []T, k int) []T
```

## アルゴリズム

- 両端キュー (deque) を用いた O(n) のスライド最小値/最大値
- 蟻本 4.4 P.300 を元に実装
