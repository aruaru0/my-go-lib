# cyclesum

一意に次の遷移が決まる決定的なシステム（関数）において、初期値から $N$ ステップ遷移したときに出現する値の累積和を、ループ（周期性）を検出することで高速に計算するアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- ゲームやパズルで、同じ操作を何十億回も繰り返したときのスコアや状態の総和の算出
- 疑似乱数生成器や簡易オートマトンによる状態遷移における、特定の累積指標の計算

## なぜ使うのか（メリット）

- 遷移が周期に入ると、それ以降のステップはループの掛け算と余りの計算のみで処理できるため、ステップ数 $N$ が $10^{18}$ などの超巨大な値であっても、周期の長さ $M$ に対して $O(M)$ の時間で結果を求められます。

---

## 関数

```go
func CycleSum(start, N, mod int, next func(int) int) int
```

## CycleSum

`next` で定義される数列の最初の `N` 項の総和を、`start` から開始して計算します。繰り返される mod の剰余に基づいてサイクルを検出し、そのサイクルを利用して N の値にかかわらず O(mod) 時間で総和を計算します。
