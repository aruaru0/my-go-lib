# gacha

全 $n$ 種類のアイテムが等確率で排出されるガチャにおいて、すべてのアイテムを少なくとも1回以上当てる（コンプリートする）までに必要なガチャの回数の期待値を算出します（クーポンコレクター問題）。

## 主なユースケース（どういう時に使うか）

- ソーシャルゲームやランダムカプセルトイにおける、全種類コンプリートに必要な平均費用の見積もり
- ネットワークパケットがランダムに再送される環境での、全パケットを受信し終えるまでの期待時間の予測

## なぜ使うのか（メリット）

- 数学的な調和数 $H_n = \sum_{i=1}^n \frac{1}{i}$ と期待値の線形性を利用し、 $O(n)$ の単純ループで正確な期待値を $O(1)$ の追加メモリで求められます。

---

## 関数

```go
func GachaExpectation(n int) float64
```

## GachaExpectation

クーポンコレクター問題において、`n` 種類すべてのアイテムを集めるために必要な期待試行回数を返します。`n * H_n` として計算されます。ここで `H_n` は n 番目の調和数です。
