# Clique — 最小クリーク被覆

グラフの頂点集合を、互いに隣接し合う頂点同士の集まり（クリーク）に分割する際、必要なクリークの最小数を求めるアルゴリズムです（最小クリーク被覆問題）。

## 主なユースケース（どういう時に使うか）

- **タイムテーブルやスケジューリング問題で、競合しないタスク同士を同じグループ（クリーク）にまとめてグループ数を最小化する**
- 類似するデータ同士をまとめ、かつグループ内はすべて互いに類似している状態にするクラスタリング

## なぜ使うのか（メリット）

- NP困難である最小クリーク被覆問題を、ビット演算を用いた動的計画法（Bit DP）により、頂点数 $N$ が小さい場合に $O(3^N)$ または $O(N \cdot 2^N)$ で厳密に解くことができます。

---

## 関数

```go
func MinCliqueCover(N int, edges [][]int) int
```

MinCliqueCover は、無向グラフのすべての頂点を被覆するために必要な最小クリーク数を返します。ビットマスク DP を使用します。

クリークとは、すべての頂点対が直接辺で結ばれている頂点の部分集合です。
