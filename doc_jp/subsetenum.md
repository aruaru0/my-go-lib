# SubsetEnum — セットビットの部分集合列挙

与えられた集合（あるいはビット列で表された要素群）から、考えられるすべての部分集合を列挙するアルゴリズムです。

## 主なユースケース（どういう時に使うか）

- ビット表現を用いた小規模な状態に対する総当たり探索
- 特定の親集合に含まれる子グループの全列挙

## なぜ使うのか（メリット）

- ビット演算のトリックを用いることで、無駄な状態を一切生成することなく、親集合の持つすべての部分集合だけを効率的に列挙できます。

---

## 関数

```go
func Subsets(i int) []int
```

Subsets は `i` のすべての非ゼロ部分マスクを返します。たとえば、`Subsets(0b1110)` は `[0b1110, 0b1100, 0b1010, 0b1000, 0b0110, 0b0100, 0b0010]` を返します。

標準的な部分マスク列挙パターン `for j := i; j != 0; j = (j - 1) & i` を使用します。
