# Circle — 円と円の交点

2次元平面上における2つの円の交点（座標）を幾何学的に計算するモジュールです。

## 主なユースケース（どういう時に使うか）

- 2つの円センサーの検知範囲の重なりや、交点の座標特定
- 平面幾何の問題における、円と円の接触・交差判定および交点探索

## なぜ使うのか（メリット）

- 余弦定理と三角関数に基づく数学的公式を用いて、ループ処理なしで $O(1)$ の時間計算量で正確な交点座標を求められます。

---

## 型

```go
type PointF struct {
	X, Y float64
}
```

## 関数

```go
func CircleCross(p0, p1 PointF, r1, r2 float64) []PointF
```

CircleCross は 2 つの円の交点を返します。円が交差しない場合 (離れている、または同心円) は nil を返します。
