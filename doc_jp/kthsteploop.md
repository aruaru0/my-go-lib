# KthStepLoop — ループ検出付き K ステップグラフ探索

有限な状態数を持つシステムにおいて、初期値から $K$ ステップ進んだ先を、状態の重複（ループ）を検出して剰余を取ることで高速に計算するアルゴリズムです（ダブリングを用いない省メモリ版）。

## 主なユースケース（どういう時に使うか）

- 状態遷移の選択肢が固定されており、ステップ数 $K$ が非常に大きく、かつ頂点数 $N$ がメモリに乗る規模の場合のシミュレーション

## なぜ使うのか（メリット）

- ダブリング用の巨大なテーブル（$O(N \log K)$）を必要とせず、 $O(N)$ のメモリスペースだけで、超巨大な $K$ に対しても $O(N)$ の時間で結果を求められます。

---

## 関数

```go
func KthStepLoop(N int, K int64, next []int) int
```

KthStepLoop は、ノード 0 から開始して正確に K ステップ後に到達するノードを返します。KthStep とは異なり、マップベースのループ検出を使用するため、K が非常に大きくグラフにサイクルが含まれる場合に効率的です。
