# Segment — 線分の交差判定

2次元平面上における線分の交差判定や、交点座標の計算などを行う幾何モジュールです。

## 主なユースケース（どういう時に使うか）

- **ゲームにおける弾丸や物体の移動軌跡（線分）と壁との衝突判定**
- **地図データ（GIS）における道路や境界線同士の交点抽出**

## なぜ使うのか（メリット）

- ベクトルの外積を用いた符号判定や数学的な直線の交点公式を利用し、 $O(1)$ の時間計算量で誤差を抑えつつ正確に交差情報を算出できます。

---

## 関数

```go
func SegmentsIntersect(ax, ay, bx, by, cx, cy, dx, dy int) bool
```

SegmentsIntersect は、線分 AB と線分 CD が交差する場合に true を返します (端点での接触は交差とみなしません)。

外積の符号テストを使用します。
