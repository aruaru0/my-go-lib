# ConvexHull — Monotone Chain

2次元平面上に与えられた複数の点集合をすべて囲む最小の凸多角形（凸包）の頂点集合を求めるアルゴリズムです（モノトーンチェーン法など）。

## 主なユースケース（どういう時に使うか）

- **地理空間データ処理において、複数の地点を包含する最小の境界（サービスエリアや領土など）を画定する**
- **物理シミュレーションやゲーム開発における、複雑な物体の境界判定（コライダー）の単純化**

## なぜ使うのか（メリット）

- 点の数を $N$ としたとき、ソートを介して $O(N \log N)$ という非常に高速な計算量で凸包を構築できます。

---

## 型

```go
type Point struct {
	X, Y int
}
```

## 関数

```go
func ConvexHull(pts []Point) []Point
```

ConvexHull は、Monotone Chain (Andrew のアルゴリズム) を使用して、点集合の凸包を左端の点から反時計回り順で返します。

すべての点が同一直線上にある場合は 2 つの端点を返します。単一の点の場合はその点を返します。
